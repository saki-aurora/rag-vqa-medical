What each NEW notebook must do (very specific)
----------------------------------------------

(3) 02_validate_splits_and_integrity.ipynb
- Verify every sample has an image file on disk (no missing paths)
- Check duplicates across splits (train/test leakage)
- Confirm required fields exist and are consistent:
  question, answer, question_class, complexity, transformed_flag (or equivalent)
- Output a single canonical dataset file used by all modeling:
  out/manifest_x1.parquet  (single source of truth)

(4) 02_metrics_and_answer_normalization.ipynb
- Define answer normalization:
  lowercase, strip punctuation, collapse whitespace
- Implement metrics:
  Exact Match (EM)
  Token-F1
  (Optional) ANLS / edit-distance soft match
- Export reusable functions:
  utils/metrics.py (or equivalent)

(5) 01_zeroshot_qwen2_5_vl_and_medgemma.ipynb
- Run modern VLM zero-shot baselines:
  Qwen2.5-VL zero-shot
  MedGemma (or MedGamma if that’s what you can run) zero-shot
- Evaluate:
  overall
  per question_class
  per complexity (1/2/3)
  original vs transformed
- Save standardized predictions:
  out/qwen2_5_vl_zeroshot/predictions.jsonl
  out/medgemma_zeroshot/predictions.jsonl
- Also save standardized metrics.json beside each run.

(6) 01_unified_eval_tables_figures.ipynb
- Load predictions from:
  best classical baselines (pick 2–3 max)
  BLIP/BLIP-2 (optional, only if already working)
  Qwen2.5-VL + MedGemma zero-shot
  (and LoRA runs if you did notebook #7)
- Compute metrics using the same normalization + utils/metrics.py
- Export thesis-ready assets:
  tables/leaderboard.csv
  tables/breakdown_by_class.csv
  tables/breakdown_by_complexity.csv
  tables/original_vs_transformed.csv
  figures/*.png
- (Optional) qualitative error gallery (20–40 examples)
