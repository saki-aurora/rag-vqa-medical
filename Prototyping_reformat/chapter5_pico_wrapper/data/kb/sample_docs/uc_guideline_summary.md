# UC Endoscopic Severity Summary

## Scope
This internal summary document describes high-level interpretation of ulcerative colitis
severity in endoscopic settings.

## Severity Anchors
- Mayo endoscopic subscore (MES) ranges from 0 to 3.
- MES 0 to 1 is commonly used as a remission-oriented threshold in reporting.
- MES 2 to 3 represents active endoscopic inflammation.

## Monitoring Notes
- Endoscopic severity is one component of treatment monitoring.
- Symptom reports and laboratory context are needed for full clinical assessment.
