## 🎯 Project Overview  

This thesis investigates the integration of **Visual Question Answering (VQA)** with **Retrieval-Augmented Generation (RAG)** to enhance diagnostic assistance in **gastrointestinal imaging**, with a particular focus on **ulcerative colitis**.  

The aim is to develop a system that:  
- Interprets medical images (endoscopy/colonoscopy).  
- Answers clinically relevant questions with **context-aware reasoning**.  
- Retrieves supporting evidence from **medical knowledge sources**.  
- Provides **explainable insights** to support clinicians in decision-making.  

Ultimately, the project contributes to **AI-assisted diagnostics**, bridging the gap between visual understanding, natural language reasoning, and evidence retrieval.

## 🌟 Key Outcomes  

By the end of this thesis, the project will deliver:  
1. A **working VQA-RAG prototype** for gastrointestinal image-based diagnostics.  
2. A **comparative evaluation** of baseline VQA models vs. VQA-RAG.  
3. Research contributions in:  
   - Domain-specific VQA datasets (colonoscopy/ulcerative colitis).  
   - Efficient retrieval mechanisms for medical QA.  
   - Explainability in AI-driven clinical support.
